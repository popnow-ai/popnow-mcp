# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

- Preferred: open a [private security advisory](https://github.com/popnow-ai/popnow-mcp/security/advisories/new) on GitHub.
- Or email **support@popnow.ai** with "Security" in the subject.

Include the affected component (the hosted server at `https://api.popnow.ai/mcp` or the OAuth flow), steps to reproduce and the impact you observed. We will acknowledge your report and keep
you updated while we fix it.

## Revoking access

To cut off a connected AI app, use **Account settings → Devices → Connected AI apps** on
[popnow.ai](https://popnow.ai/me/settings/sessions). For API keys, see
[popnow-api-mcp](https://github.com/popnow-ai/popnow-api-mcp/blob/main/SECURITY.md).
